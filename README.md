# 🚀 Pokémon Explorer  
A **Next.js 15** project for exploring Pokémon details, built with **Tailwind CSS**.  

## **🛠️ Getting Started**  

### ** 1️. Clone the Repository**  
git clone https://github.com/your-username/pokemon-explorer.git
cd pokemon-explorer

### ** 2️. Install Dependencies**  
npm install

### ** 3️. Run Development Server**  
npm run dev
